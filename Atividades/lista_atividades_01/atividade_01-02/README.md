## Atividade 02

Crie um programa que receba uma vez o nome e a idade do usuário e em seguida mostre os filmes em cartaz  em 5 salas de cinema:

 - A volta dos que não foram (Livre)
 - A roda quadrada (12 anos)
 - As tranças do rei careca (14 anos)
 - Poeira em alto mar (16 anos)
 - A vingança do frango assado (18 anos)

O usuário irá escolher a sala onde o filme desejado esta passando. Caso o usuário não tenha idade, 
o programa impede sua entrada e reexibe a lista para que o mesmo possa escolher outro filme.
Caso o usuário tenha a idade minima o programa grava em arquivo o bilhete do filme e encerra o programa.
